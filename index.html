Proyectos Destacados

                    

                        

                            

                                
 Product-Admin

                                
Sistema integral de gestión de inventario de productos. Backend robusto desarrollado con Spring Boot, frontend moderno con Angular, base de datos PostgreSQL. Incluye gestión de productos, inventario, reportes y documentación API con Postman.

                                

                                    
                                    
                                    
                                

                                

                                    Repositorio
                                

                            

                        


                        

                            

                                
 Password Generator

                                
Generador de contraseñas moderno y seguro con React y Vite. Crea contraseñas fuertes y aleatorias con opciones personalizables. Incluye indicador de fortaleza en tiempo real, historial de últimas 10 contraseñas, y 100% privado - todo se procesa localmente sin transmitir datos.

                                

                                    
                                    
                                    
                                

                                

                                    Repositorio
                                

                            

                        


                        

                            

                                
 Sistema de Votación Electoral

                                
Plataforma de votación con módulo admin para generar reportes PDF (votantes, abstenciones, resultados) y módulo votante con acceso por cédula. Responsive y funcional en todas las plataformas. Implementado en el instituto para elecciones del consejo estudiantil.

 Carrito de Compras Real-Time

                                
Carrito de compras en tiempo real con sincronización de datos entre múltiples clientes usando Socket.IO. Backend robusto con Express.js y PostgreSQL, frontend responsive con JavaScript vanilla y diseño moderno.

 Sistema de Reserva

                                
Sistema de reservas desarrollado en Kotlin puro con base de datos SQLite. Containerizado con Docker para fácil despliegue y sincronización en la nube con Firebase para acceso en tiempo real desde cualquier dispositivo.
